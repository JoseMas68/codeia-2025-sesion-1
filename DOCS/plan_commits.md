# Plan de Commits y Tags

## Ejemplo de flujo
1. `init`: Estructura base y dependencias.
2. `feat/api`: Integración endpoints TMDB.
3. `feat/model`: Normalización y modelo de datos.
4. `fix/bug`: Corrección de errores.
5. `docs/update`: Actualización de documentación.

## Puntos de tag
- `v0.1.0`: MVP funcional.
- `v1.0.0`: Release estable.
